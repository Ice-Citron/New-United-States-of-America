# Introduction

Personal project — developing a **400 km/h interceptor drone** with a custom-built gimbal and Raspberry Pi-based computer vision for autonomous last-mile target tracking.

*This is an in-progress project (2026–present).*

---

# Prototype Build

The Interceptor uses a custom 3D-printed fixed-wing airframe designed for high-speed flight. The red fuselage was printed in PLA with motor mount tubes integrated into the design.

# The Project

**Interceptor Drone Specs (Target):**
- **Speed:** 400 km/h
- **Vision:** Raspberry Pi with onboard computer vision (YOLO-based)
- **Tracking:** Autonomous last-mile target tracking via custom gimbal
- **Purpose:** Research platform for high-speed autonomous flight
