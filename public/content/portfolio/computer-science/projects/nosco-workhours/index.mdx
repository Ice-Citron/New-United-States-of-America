# Introduction

In 2024, I was contracted by **Nosco Asia (S) Pte Ltd** in Singapore to develop a workforce management application. This was my first professional full-stack development project, building an enterprise solution from scratch.

The app was built with **ReactJS**, **Firebase**, and **Google Cloud Platform**, featuring real-time data synchronisation, user authentication, and a responsive UI with Tailwind CSS.

# Tech Stack

- **Frontend:** ReactJS with Tailwind CSS for responsive, mobile-first UI
- **Backend:** Node.js with TypeScript
- **Database:** Firebase Firestore with real-time synchronisation
- **Auth:** Firebase Authentication
- **Hosting:** Google Cloud Platform
- **Features:** Employee time tracking, shift management, reporting dashboards, role-based access control
