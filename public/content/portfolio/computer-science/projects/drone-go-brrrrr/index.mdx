# Introduction

**Drone-go-brrrrr** is a reinforcement learning project demonstrating the superior performance of **Liquid Time-Constant (LTC) Neural Networks** over traditional MLP baselines for drone control in challenging wind conditions. Trained using **PPO (Proximal Policy Optimization)**, the agents navigate a 2D drone environment with varying wind difficulties.

# Key Results

Comprehensive evaluation across 5 wind difficulty levels showed **Liquid Neural Networks consistently outperform MLP baselines**:

- Liquid NN achieves **2x higher rewards** in easy-to-medium conditions
- Liquid NN survives **13% longer** in extreme wind conditions
- Liquid NN maintains **perfect survival** (500 steps) in conditions where MLP also succeeds
- **Superior generalization** to unseen/holdout difficulty levels

*Results based on 20 evaluation episodes per difficulty level.*

# Architecture

**Core Components:**

1. **Custom Drone Environment** (`env/drone_env.py`) — 2D navigation with wind dynamics across 5 difficulty levels (No Wind, Mild, Medium, Chaotic, Extreme), with configurable turbulence and gusts
2. **Liquid Neural Network Policy** (`models/liquid_policy.py`) — LTC cell-based feature extractor with continuous-time dynamics for better temporal modeling, integrated with Stable-Baselines3 PPO
3. **MLP Baseline** (`models/mlp_baseline.py`) — Traditional 2-layer MLP (64, 64) for fair comparison
4. **Training Pipeline** — Curriculum learning and random difficulty sampling support
5. **3D Visualization** — Interactive Three.js visualization with real-time WebSocket streaming, plus 2D Pygame demos

The Liquid Neural Network approach leverages **continuous-time dynamics** for superior temporal modeling, which is critical for handling unpredictable wind patterns in real-time drone control.
