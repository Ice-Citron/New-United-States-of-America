# Introduction

I'm training robotic arms (UR5e and SO-101) via **reinforcement learning** in **NVIDIA Isaac Sim**, then transferring learned policies to real hardware via **sim-to-real transfer**.

I 3D-printed and assembled an SO-101 robotic arm in my personal makerspace, and I'm working on modifying it to improve dexterity.

*This is an in-progress project (2026–present).*

# Approach

1. **Simulation** — Train robotic arm policies in NVIDIA Isaac Sim with Isaac Lab
2. **Validation** — Additionally validate policies in MuJoCo and Gazebo
3. **Sim-to-Real** — Transfer learned policies to physical SO-101 arm
4. **Hardware** — Training runs on local RTX 5090 GPU

**Target Tasks:**
- Assemble complex Lego sets (e.g., Millennium Falcon)
- Handle cable management for data center server-rack assembly

The thesis: if a robot can handle this level of dexterity, it can handle most low-cost manual labour tasks — with significant implications for manufacturing automation.
