# Introduction

I'm training robotic arms (UR5e and SO-101) via **reinforcement learning** in **NVIDIA Isaac Sim**, then transferring learned policies to real hardware via **sim-to-real transfer**. The ultimate goal is autonomous **Lego assembly** and **data center cable management** -- tasks that demand extreme dexterity.

I 3D-printed and assembled an SO-101 robotic arm in my personal makerspace, and I'm working on modifying it to improve precision for fine manipulation tasks.

*This is an in-progress project (2026--present).*

The full assembly -- wiring servos, routing cables, and calibrating joints -- was done on a custom workbench I set up as a personal makerspace.

# Development Roadmap

The project follows three progressive phases, moving from foundational infrastructure to a fully autonomous manipulation system:

### Phase 1: Infrastructure and Foundations (Current)

- Automated sync pipelines between local Windows workstation (RTX 5090) and cloud Linux GPU servers (Vast.ai, Tensordock -- using RTX 6000 Pro and L40 hardware)
- Foundational Isaac Sim training via Lychee AI tutorials (scene creation, spawning prims, rigid/deformable body simulation, articulated robot control)
- Core RL environment setup with physics parameters in Isaac Lab

### Phase 2: Hardware Design and Simulation Research

- CAD and prototype hardware modifications for the SO-101 arm to support high-precision gripping and Lego manipulation
- Reproduce state-of-the-art robotics research papers within Isaac Sim
- Import and configure an accurate digital twin of the customised SO-101 arm
- Integrate ROS2 with Isaac Sim for seamless sim-to-real communication
- Participate in the **Intrinsic AI for Industry Challenge** (cable management task using Gazebo, Isaac Sim, and Intrinsic Flowstate)

### Phase 3: The Capstone -- Lego Assembly

- Develop custom RL reward functions for spatial awareness, precision gripping, and structural Lego piece snapping
- Train the agent using cloud compute clusters, iterating continuously on the digital twin
- Deploy the trained model to the physical SO-101 hardware for real-world testing and validation

**Isaac Sim and Isaac Lab** are used as the primary simulation environment. Isaac Lab provides GPU-accelerated parallel environments for training RL policies on articulated robots. The pipeline includes:

- **Scene creation** using OpenUSD and Omniverse
- **Rigid/deformable body simulation** for realistic object interaction
- **Articulated robot control** via joint effort targets and kinematic controllers
- **Domain randomisation** across multiple simulators (Isaac Sim, MuJoCo, Gazebo) for robust sim-to-real transfer

The **lerobot** framework (from Hugging Face) is integrated for imitation learning and policy deployment. The ACT (Action Chunking with Transformers) policy architecture enables learning from small demonstration datasets, which is particularly valuable for fine manipulation tasks where reward engineering is difficult.

# Tech Stack and Infrastructure

**Simulation:**
- NVIDIA Isaac Sim and Isaac Lab (Omniverse)
- MuJoCo and Gazebo (cross-validation)
- OpenUSD for scene description

**AI / ML:**
- PyTorch for RL policy networks
- lerobot (Hugging Face) for imitation learning / ACT policies
- GRPO and custom reward functions

**Robotics:**
- ROS2 for sim-to-real communication
- Custom kinematic controllers
- Intrinsic Flowstate (for AIC challenge)

**Hardware:**
- SO-101 6-DOF robotic arm (3D printed, modified)
- Bambu Lab A1 3D printer (PLA, PET-CF)
- Local: NVIDIA RTX 5090 (Windows workstation)
- Cloud: Vast.ai and Tensordock (RTX 6000 Pro, NVIDIA L40)

**Target Tasks:**
- Assemble complex Lego sets (e.g., Millennium Falcon)
- Handle cable management for data center server-rack assembly (SFP modules, LC/SC fiber optic connectors)

The thesis: if a robot can handle this level of dexterity, it can handle most low-cost manual labour tasks -- with significant implications for manufacturing automation.
