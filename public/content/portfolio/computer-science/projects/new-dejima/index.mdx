# Introduction

**New Dejima** is an autonomous AI agent revenue system — a pipeline where AI agents generate Android apps from natural language, compile them, deploy to real hardware, run vision-based QA, and self-debug — all with **no human-in-the-loop**.

Built on top of **OpenClaw**, this project also includes an autonomous marketing engine using ElevenLabs, Veo 3.1, and Lyria to publish AI-generated videos to YouTube Shorts, achieving **1,200+ views in 30 hours**.

*This is an in-progress project (expected completion: June 2026).*

# Architecture

**The autonomous pipeline:**

1. **App Generation** — AI agents take natural language specs and generate complete Android applications
2. **Compilation & Deployment** — Automated build and deploy to real hardware
3. **Vision-Based QA** — Automated quality assurance using computer vision to verify app functionality
4. **Self-Debugging** — When QA fails, the system automatically diagnoses and fixes issues

**Marketing Engine:**
- **ElevenLabs** for voice generation
- **Veo 3.1** for AI video generation
- **Lyria** for music generation
- Autonomous publishing pipeline to YouTube Shorts

**Revenue Tracking:**
- Real-time economic tracking layer via Paid.ai
- Measuring revenue-per-token vs cost-per-token
- Target: $10K USD ARR by end of 2026
